## 组织约定

- 编号即阅读顺序：每模块 = 规格层（`00-README` / `01-spec` / `02-interfaces` / `03-nfr`）+ 现状快照（`04-current.md`，与目标的差距用于派生 issue）+ 设计子区（`design/`，机制级设计，不参与编号）。
- 模块外区：架构总纲、调研等跨模块材料按需单列，不占模块编号。

## 阅读顺序

<先读什么建立整体基线与公共契约，再按模块读规格层，最后看调研 / 场景等附加材料。>

## 新增模块

- 在 `docs/pdr/` 下建编号目录（编号沿用阅读顺序，不插号）；
- 补齐规格层四件套（`00-README` / `01-spec` / `02-interfaces` / `03-nfr`）与现状快照 `04-current.md`，机制细节进 `design/`；
- 在上方模块索引与阅读顺序中登记入口，明确对外接口的提供方归属；
- 涉及产品形态的决策，同步落 ADR。
