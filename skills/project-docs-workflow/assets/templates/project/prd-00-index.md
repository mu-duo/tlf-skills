## 组织约定

- **三层**：L1 = 产品与模块 `00-README.md`（人类叙事视图，不含状态）；L2 = `01-spec` / `02-interfaces` / `03-nfr` + `design/`（规范目标，唯一事实源）；L3 = `docs/current/`（实际建成形态）。
- 编号即阅读顺序：模块目录 `NN-<模块>/`，不插号。
- **链接规则**：L1 只允许同文件锚点、产品 L1 ↔ 模块 L1、模块 L1 ↔ 模块 L1；指向 L2 / Current / ADR 的链接只出现在本文件或 L2 中。
- 冲突以 L2 为准；已实现的细节不会自动提升进 L2 或 L1。
- 需要指向某项决策时，用描述性短语 + 指向稳定 ADR 文件的普通 Markdown 链接（例：支持 [离线使用](../adr/0003-offline.md)）；不转述 ADR 理由。
- 模块外区：架构总纲、调研等跨模块材料按需单列，不占模块编号。

## 新增模块

- 在 `docs/prd/` 下建编号目录，补齐 L2 四件套与模块 `00-README.md`（模块 L1）、`00-index.md`；
- 在上方模块索引与阅读顺序中登记入口，明确对外接口的提供方归属；
- 在 `docs/current/` 增补对应现状文件（不强制对齐编号）；
- 涉及产品形态的决策，同步落 ADR。
