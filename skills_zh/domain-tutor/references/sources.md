# 来源

领域没有 `path:line`。论断改锚定在来源上，而锚点只和它背后的检索一样可靠。

**硬规则：绝不编造引用。** 不编章节号，不编页码，不编作者，不编 URL，不编日期。如果某个来源既未在本次会话中检索到，也未经用户提供，该论断就是 `inferred`——无论感觉多确定，无论那本书多有名。

## `verified` 与 `inferred`

两个标记，用于 `spine.md`、`concepts/<id>.md` 和 `cheatsheet.md` 上的每个承重论断。`README.md` 和 `graph.yml` 不承载散文论断；它们从页面继承。

- **`verified`** —— 可追溯到章节 / 小节 / URL 级别的来源，**且该来源确已在本次会话中检索或提供**。读者能打开它并找到该论断。
- **`inferred`** —— 模型知识、类比、综合，或一个未被重新打开的记忆中的来源。它可能对，但没有锚定。

边界情况，已定：

| 情况 | 标记 | 理由 |
| --- | --- | --- |
| 从本次会话检索到的页面直接引用的文字 | `verified` | 可直接追溯 |
| 你很熟但没打开过的教科书 | `inferred` | 对来源的记忆不是来源 |
| 看过书的目录，章节未读 | 「该章存在」为 `verified`；你说它包含的任何内容为 `inferred` | 锚点证明结构，不证明内容 |
| 人尽皆知的公式（`F = ma`、复利） | `inferred`，注明「（标准公式；此处未复核）」 | 常见 ≠ 已检索；不要把记忆装扮成出处 |
| 你自己构造的类比（「萃取就像海绵」） | `inferred` | 它是你的，且它是模型，不是事实 |
| 跨两个已验证来源的综合 | `inferred` | 拼接是你的，即使两个前提都有锚 |
| 用户粘贴或点名并提供的来源 | `verified`，注明「用户提供」 | 提供即算检索（`../SKILL.md` §12） |
| 你只记得一半的数字、日期、人名或统计 | 省略，或说不知道 | 绝不把未核实的数字当事实断言 |
| 你在另一个来源中看到被引用的论断 | `inferred`，引用那个转引来源 | 你检索到的是引文，不是原文 |
| 你自己的计算过程 | `inferred`，并展示算术 | 可复现胜过可归属 |

拿不准时：`inferred`。多标一次只花一行；一次编造的引用会永久损害学习库的可信度。

## `sources.md` —— 至多五个

精选发生在**第一个概念页之前**。一个列了十五个来源却没有页面的学习库，是披着书目的拖延。

条目格式：每个来源一行，如 `assets/sources.template.md` 所示。

```markdown
| id | Source | Type | Part of the field | Why worth the time | Difficulty | How to use it | What not to waste time on |
| --- | --- | --- | --- | --- | --- | --- | --- |
| s1 | <title, author, edition, URL> | book / course / paper / reference / manual | <subfield or chapters> | <one sentence: what only this source gives> | intro / working / expert | <read, do, or exercise; which parts> | <sections or digressions to skip> |
```

规则：

- **最多五行。没有例外，没有「辅助」清单。** 第六个候选替换五个之一，或被丢掉。删除未使用的行；不要留空行。
- id 为 `s1`…`s5`，稳定不变。被替换的来源保留其 id 并退役，绝不复用：`s2 (retired 2026-11-14)`。
- `Source` 单元携带访问线索：书籍的版次/年份，URL 的检索日期，用户交来的材料注明「用户提供」。没有访问线索，该条目就无法让任何东西成为 `verified`。
- **属于领域的哪部分**要写概念或层级，不只是章节。读者必须能看出每个来源支撑哪个页面。
- **不要把时间浪费在什么上**是一列，不是事后补白：它是唯一能阻止用户把一本 600 页的书从头读到尾的东西。
- 每一行都必须相对另外四行挣得其位置。两周后没有任何概念页引用的来源是死重——替换或删除它，并在会话记录中说明。

选择标准，按顺序：

1. **杠杆重于完整。** 一个在合适难度上覆盖领域 60% 的来源，胜过五个各覆盖 15% 的。覆盖度以服务的概念衡量，不以读过的页数衡量。
2. **难度匹配。** 主来源必须匹配用户所在的层级。给新手一本研究专著，是用户不会读的来源；给熟练者一本通俗摘要，是会教错模型的来源。
3. **经典 vs 当前。** 基础模型优先选领域视为标准的来源，另加一个当前来源处理领域已经推进的部分。两个学派，两个条目——不是五个。
4. **可检索。** 本次会话打不开的来源，锚不住任何东西。它仍可列出，标为 `inferred`。
5. **总纲的覆盖面。** 五个来源合起来，`spine.md` 的第 1–6 部分每一部分都必须至少被一个条目支撑。第 6 部分（假定）的缺口是代价最高的缺口。

不要把时间浪费在：

- 为已有锚点的概念再找一个来源，除非两者不一致。
- 一周内不会打开的教科书。
- 把视频课程和讲座当作主锚——它们难以按小节引用，也容易被记错。
- 书目、「延伸阅读」清单，以及经典论文链。
- 你已有的一手工作的通俗摘要。
- 任何有付费墙且没有获取路径的内容。无法检索的来源是自我备忘，不是引用。
- 为了显得周全而选的来源。上限之所以存在，是因为这里的周全以写出的页数衡量，不以列出的来源衡量。

## 7 天路径

用这五个来源对领域做第一遍。它是一条路线，不是日程；一次坐仍是 10–20 分钟。

| 天 | 重点（模式） | 来源 | 产出 |
| --- | --- | --- | --- |
| 1 | 定位——用一句话说明领域、边界、核心回路（`start`） | s1 概览 | `spine.md`、含 12–40 个节点与四个层级的 `graph.yml`，提交用户纠正 |
| 2–3 | 层级 1——4–6 个没有前置的概念（`learn`） | 基础模型用 s1，第二视角用 s3 | 2–3 个概念页，各配一次即时校验 |
| 4–5 | 层级 2——机制，按依赖顺序（`learn`） | s1，应用细节用 s4 | 1–2 个概念页，达到 L2–L3；在第一次前置校验失败处停下 |
| 6 | 接缝、对比、限制；然后复习并压缩（`learn`、`drill`、`cheat`） | 对比用 s2，当前观点用 s5 | 对比边、`cheatsheet.md`、清空的到期复习 |
| 7 | 针对层级 1–2 的十题闯关考，然后报告（`exam`、`status`） | 无新来源——闯关考测的是页面 | 闯关考记录、下周计划 |

对这条路径的约束：

- 周中不获取新来源。缺口被记录，不被补丁。周中添加来源，正是五来源上限死掉的方式。
- 如果领域很大，这一周只覆盖层级 1–2。在第 1 天就说明；不要把四个层级压进七天还称之为覆盖。
- 如果第 1 天的纠正会话实质改变了概念图谱，这一周的路线跟随图谱，而不是这张表。

## 已知缺口

`sources.md` 末尾的短清单，至多三条，每条一行：

- `<五个来源都未覆盖好的领域部分>` —— 它影响哪些概念页。
- `<当前为 inferred 的论断>` —— 什么能了结它，去哪里找。
- `<s1 与 s2 之间的冲突>` —— 领域当前跟随哪一个，或「未解决」。

缺口闭合时删除该条；不要把已解决的清单作为历史保留。在这里标出的缺口，比日后编造一条引用更便宜，也是页面显得单薄时最该先读的东西。

## 冲突处理

两个来源在某个承重论断上不一致。不要悄悄选一个，也不要取平均。

1. **记录在概念页中**，放在诸如 `## Disagreement` 的标题下，若范围很窄就放进 **When it holds**：`[s1]` 说 X，`[s2]` 说 Y，写到章节/小节级别。
2. **说明领域当前跟随哪一个**，以及依据：时效、采用度，或新方法取代旧方法。如果从来源无法得知，就说「在我手上的来源中未解决」。
3. **保持基础模型单一。** 页面只教一个版本；另一个是一行加上原因。400 词的页面里放两套并行解释，教出的用户能说出两者，却两个都不会用。
4. 冲突未解决期间，在 `graph.yml` 中把该概念标为 `verified: inferred` —— 它没有单一的有锚论断集。
5. **在基础模型达到 L2 之前绝不考查该分歧。** 到 L3，用户应能说出另一立场主张什么，以及领域为何偏向当前方向。
6. 如果分歧确属两个学派，它成为一个节点（`curriculum.md` → 竞争学派），而不是脚注。

## 当没有来源能回答一个承重问题

诚实的顺序，在同一轮内：

1. **说不知道。** 「五个来源中没有一个在小节级别回答这一点。」一行，不要一段含糊其辞。
2. **把该论断标为 `inferred`，或删掉它。** 如果页面离了它就立不住，页面就缩小。
3. **把缺口记两次**：概念页上一行——`Open: <question> — not covered by s1–s5.`——以及 `sources.md` 的**已知缺口**下一条。它会一直保留到被回答；一个没有来源就消失的缺口，是被凭空编造填上的。
4. **提议一个具体来源**：书名，以及要查的小节或章节。具体到用户十秒内就能决定。
5. **不要用看似可信的内容填补缺口。** 在缺口上写一段自信的文字，正是本文件要防止的失效模式。
6. 如果缺口完全阻塞该概念，说明它，并为这次坐另选一个概念。

## 引用卫生

- **章节 / 小节 / URL 级别。** `[s1] ch. 4`、`[s2] §2.1`、`[s3] https://… (retrieved 2026-11-01)`。这足以再次找到该论断。
- **除非你真的看到，否则不写页码。** 分页因版次和格式而异；你重构出来的页码，是额外带着自信的编造引用。
- **书籍写版次和年份。** 一个论断可能在第二版为真、第四版为假。
- **任何在线内容写访问日期。** 内容会移动；日期是让锚点诚实的东西。
- **绝不把搜索摘要当作已检索。** 打开页面，或标为 `inferred`。
- **绝不引用「文献」「标准做法」或「大多数教科书」。** 点名一个来源，或标为 inferred。
- **不编造 DOI、ISBN 或 URL。** 不确定 URL 时，只引标题和小节。
- **每个论断一个锚点。** 带三个引用的论断，通常意味着作者不确定哪一个说了它。
- 速查表可以把引用压缩为脚注标记，但每一行仍要追溯到携带完整锚点的页面。
