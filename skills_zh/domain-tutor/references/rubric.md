# 评分标准

等级由证据决定，绝不凭印象。如果你无法引用用户说过的话，并说出那是对哪个案例说的，等级就是 `L0`。

领域没有 `path:line`。锚点是**引用的回答加上产生它的案例**；对于论断而非回答，则是章节 / 小节 / URL 级别的来源 id（`sources.md`）。

## 如何评 L0–L4

| 等级 | 名称 | 所需证据 | 典型失败 |
| --- | --- | --- | --- |
| L0 | unknown | 没有正确陈述；或没有记录任何观察 | 流畅复述页面，但其中没有任何关系 |
| L1 | locate | 定位概念：属于哪个子领域、回答什么问题、依赖什么 | 词汇对，依赖错或缺失 |
| L2 | explain | 用自己的话解释机制，关系正确 | 事实对，一条箭头反了或缺失 |
| L3 | predict | 给定新案例或变体，预测结果，或判断方法是否适用；正确，且陈述了条件 | 结果对，理由错；或只有知道答案才能做出的预测 |
| L4 | apply | 在真实任务上使用它，并说出它的边界和代价 | 用得不错，但说不出何时失效、代价是什么 |

评分规则：

- **一个概念一个等级。** 一个在核心回路上讲得好、重试时讲错的概念，今天就是较弱的等级。第一次回答作为证据保留，不作为分数。
- **关系胜过词汇。** 按正确顺序背诵名字是 L1。正确连接其中两个是 L2。说出正确的关系但方向反了，至多仍是 L2——反了的箭头会预测错。
- **连贯性上限为 L2。** 事实正确但关系错误，无论多流畅都不能是 L3。预测需要可用的因果模型；箭头错了，预测正确就是运气。
- **条件是锚点。** L3 要求说出预测成立的条件。没有陈述条件的预测，只是碰巧命中的猜测。
- **L4 包含代价。** 使用一个方法是 L3 级别的回忆。L4 要求说出它的代价、它在何处不再适用——即页面的 **When it holds** 一节，用用户自己的话。
- **案例必须是新的。** L3 和 L4 在概念页中没有的案例上评定。用户已经读过答案的案例，测的是记忆，不是迁移。
- **没有观察就没有等级。** 空白的即时校验、被跳过的即时校验，或「直接告诉我」的会话，记录 `L0`，证据为「无观察；拒绝校验」。不得把旧等级记为已确认。

## 证据记录

存储观察，而不是标签。没有证据的等级无法重新评级，无法驱动复习，还会把一个无法信任的论断交给下一个 agent。

好：

```yaml
- id: extraction-yield
  canonical: extraction yield
  tier: 2
  level: L3
  confidence: 0.8
  accuracy: 0.5
  evidence:
    - "2026-10-30: \"yield fell because water passes through faster\" — case: same recipe, finer grind, cup tastes sour — gap: grind also widens the particle spread; the answer is not one-directional"
    - "2026-10-30: \"they measure TDS differently\" — case: why two roasters publish different target yields — gap: could not name the instrument or the correction"
  misconceptions:
    - "finer grind always raises extraction"
  sources: [s1]
  verified: verified
  next_review: 2026-11-04
```

差：

```yaml
- id: extraction-yield
  level: L3
  notes: "Learner understands extraction well."
```

差的记录没有案例、没有引用的回答、没有具体缺口、没有日期。它无法产生下一个问题，事后发现错了也无法纠正。

更多差模式：

| 模式 | 为何失败 |
| --- | --- |
| `level: L3`，证据是「回答得很好」 | 没有预测，没有案例；无法验证，无法复现 |
| 把 agent 的解释存作证据 | 衡量的是 agent，不是用户 |
| 「已掌握」 | 是判定，不是观察 |
| 一条记录里塞五个概念 | 无法分别评级、排期或复习 |
| 「那本讲咖啡的书，关于萃取的一章」，没有小节也没有引用 | 之后无法定位纠正点 |
| 证据是主题而不是回答（「聊了研磨」） | 没有可供重新评级的内容 |
| `confidence` 在给出分数之后才记录 | 已被污染；校准失去意义 |
| 一条记录里两个等级（「回路上 L2，应用上 L4」） | 选取今天证据支持的那个等级 |

## 信心与准确度

两者都是 `[0, 1]` 区间的数字。

- `confidence` — 在评分前问，与问题在同一条消息里：「你有多确定，0 到 1？」记录他们说出的数字，不是他们的回答应得的数字。
- `accuracy` — 给这次作答打分：
  - `1.0` — 正确、有序、关系正确，且陈述了条件。
  - `0.5` — 正确但有一条关系断裂或缺失，或论断正确但未陈述条件。
  - `0.0` — 错误、方向反了，或没有作答。
- `accuracy` 是该概念**最近三次**观察的平均值，因此一个固定的误解会推动这个数字，一次幸运的回答不会。

校准：

```
calibration_error = confidence - accuracy
```

| 值 | 解读 | 行动 |
| --- | --- | --- |
| `> 0.3` | 过度自信 | 先复习。在该值降到 0.3 以下之前，不要在该概念所属层级开启新材料。 |
| `0.1 .. 0.3` | 略微过度自信 | 下次会话多做一次校验。 |
| `-0.1 .. 0.1` | 已校准 | 正常间隔。 |
| `< -0.1` | 信心不足 | 说一次；他们知道的比自己以为的多。不是阻塞项。 |

过度自信优先。信心不足的用户会求助；过度自信的用户会把模型用到领域之外，并自信地犯错——那正是 `spine.md` 第 6 部分要防止的失败。

按概念报告校准，绝不要报告整个会话的平均值。一个校准糟糕的概念会藏在一个好看的平均值里。负校准永不阻塞层级门槛；门槛只拒绝过度自信。

## 复习排期

根据评分**之后**的等级设置 `next_review`：

| 等级 | 间隔 | 理由 |
| --- | --- | --- |
| L0 | 1 天 | 没有可拉开的间隔；先重建锚点 |
| L1 | 1 天 | 不使用的话，定位能力衰减很快 |
| L2 | 3 天 | 解释需要一次巩固 |
| L3 | 7 天 | 预测更稳定，但仍脆弱 |
| L4 | 21 天 | 应用能力可迁移；偶尔检查 |

规则：

- **复习失败降一个等级，并把间隔重置**为新等级的值。不要减半、不要延长、不要在同一等级「明天再试」。
- **延长只有一次，且只能一次。** L3 的复习通过可延长到 14 天，L4 到 30 天。不要连续延长；下一轮回到表格。
- `drill` 选择 `next_review <= today` 的概念，按 `calibration_error` 降序，再按最早的 `next_review` 排序。
- **一次复习最多 12 个概念。** 疲劳会产生假阴性，而一个假阴性会污染档案数周。
- 没有 `next_review` 的概念视为现在到期；第一次观察设定它。
- 被跳过的概念保留原日期。绝不推进一次没有发生的复习。

## 层级门槛

四个层级，`Novice` / `Beginner` / `Practitioner` / `Adept`（`../SKILL.md` §7）。门槛是算术，不是判断：

```
gate(T) passes iff
  for every concept in tier T, and every prerequisite ancestor of those concepts:
      level >= L2
  and max over that set of (confidence - accuracy) <= 0.3
```

说明：

- 检查覆盖该层级的**前置闭包**，而不只是该层级自己的列表（`../SKILL.md` §7）。它依赖的某个概念停在 L1 时，层级 3 无法开启。
- `min_level` 与 `max_calibration_error` 按层级存于 `graph.yml:tiers[].gate`，不得为了让门槛通过而修改。
- `accuracy` 未设置的概念没有观察，以 `L0` 不通过门槛。自评不进入算术。
- 负校准通过。信心不足不是知识缺陷。
- 门槛**在闯关考上**评估，针对正在离开的层级。通过一次使 `graph.yml:tier_current` 加一；没有别的东西能推进它。

**门槛不通过时：**

1. 点名阻塞的概念——id、等级、校准误差。至多五个，按阻塞严重程度排序。
2. 不要运行晋级闯关考。仍可为获取信息而运行闯关考；事先说明它不能晋级。
3. 把阻塞项的 `next_review` 设为今天或明天并运行 `drill`，或对最低的那个运行 `learn`。
4. 在会话记录中写下门槛算术，让下次会话看到同样的数字，而不是重新推导。
5. 绝不降低阈值，绝不把 `0.31` 向下取整，绝不把未经观察的概念当成「大概没问题」。

## 闯关考流程与计分

十道题，一次一道，先于任何晋级。构成固定：

| 槽位 | 数量 | 目标等级 | 问题形态 |
| --- | --- | --- | --- |
| foundational | 3 | L1 locate | 「这属于领域的哪一部分、它回答什么、它依赖什么」 |
| applied | 3 | L2 explain | 「用自己的话解释机制」 |
| boundary | 2 | L3 predict | 「这是一个你没见过的案例——会发生什么，方法是否适用」 |
| expert | 2 | L4 apply + boundary | 「在这个任务上用它，然后说出它的边界和代价」 |

十道题至少覆盖六个不同概念。绝不要围绕一个概念问十道题；那测的是一页，不是一个层级。

槽位标签是**难度**，不是层级。`foundational` / `applied` / `boundary` / `expert` 不映射到 `Novice` / `Beginner` / `Practitioner` / `Adept`；层级闯关考只是需要比它所测层级更难的问题。

计分：

- 每道回答按 **/10** 计分，对照该槽位目标等级的 L0–L4 证据。
- 逐题记录：分数、对在哪里、确切的缺口，以及只针对该缺口的重讲。
- 弱回答（≤4/10）获得**一次**追问。第一次回答作为主要证据保留；追问单独记录。
- 总分为 **/100**。报告最强领域、最弱领域、带日期的复习计划，以及**五道**挑战题。
- **晋级需要三者同时满足：** 被测层级满足 §7 门槛；总分至少 100 分中的 70 分；至少一道 expert 槽位回答得分 6 或以上。其余任何情况都是暂不晋级。完全由 foundational 题堆出的高分不晋级。
- 只有 `exam` 能晋级。晋级时，写入 `graph.yml:tier_current`，再据此渲染 `index.yml` 行和 `README.md`（`session-loop.md` → 收尾）。`learn` 可以报告门槛已通过；它不能推进层级。

防注水规则：

| 主张 | 为何不算 |
| --- | --- |
| 「看到答案我就知道了」 | 揭示之后才做出的预测不是证据 |
| 流畅、结构良好、没有内容的回答 | 流畅的空话是 L1–L2 |
| 标签对，关系错 | L1；会命名不等于会 |
| 公式正确但无条件 | 上限为 L2；无法用到新案例 |
| 提示之后表示同意 | 模型是提示给的，不是用户的 |
| 逐字复述页面上的句子 | 对措辞的回忆，至多 L2 |
| 「我在这上面花了 20 个小时」 | 时间是输入，等级是输出 |
| 自评「我大概 4 分」 | 是先验，不是测量 |
| 三次失败后一次答对 | 今天的等级是较弱的那一个 |
| 结果对，因果故事错 | L2；运气不是模型 |

闯关考失败是信息，不是判决。记录失败的槽位，只重讲那些缺口，安排复习，并说明下次尝试何时合理（不早于阻塞概念达到 L2）。

## 会话级评分

会话结束时，记录到 `sessions/YYYY-MM-DD.md` 和 `graph.yml`：

- 模式、目标概念，以及写就或纠正的页面——写明改动的小节，不要写「已更新」。
- 每个触及的概念及其等级变化（`L1 → L2`，或「未变，复习通过」）。
- 最强的误解，**逐字**记录，以及它在哪个小节被纠正。
- 每个触及概念的信心、准确度和校准误差。
- 层级门槛是否通过，若该层级相关则带上计数。
- 若运行了闯关考：总分、逐槽位弱项、决定、下次尝试的条件。
- 唯一的下一个动作，取六种模式之一，外加目标 id。

然后是诚实那一句：

> 一次既无等级变化、也无误解记录的会话，通常是讲师在讲课的会话。在记录中这样写。

不要为了填满字段而编造误解，也不要为从未给出的回答记录等级。空的证据记录是真实的记录。
