# 评分标准

等级只依据证据给出，绝不依据印象。如果你无法引用用户说过或做过什么，等级就是 `L0`。

## 如何评定 L0-L4

| 等级 | 名称 | 需要的证据 | 典型失败 |
| --- | --- | --- | --- |
| L0 | unknown | 没有正确表述；或没有记录任何观察 | 自信流畅但毫无锚点的总结 |
| L1 | locate | 给出功能或术语后，无需帮助就能指出正确的文件 | 路径对，符号错 |
| L2 | explain | 不经提示、按顺序说明代码做什么以及为什么 | 用词对，顺序反 |
| L3 | predict | 在看到之前就说出接下来会发生什么、或什么会坏；且正确 | 预测跟在揭示之后 |
| L4 | apply | 规划正确的变更：文件、调用点、测试、影响范围 | 说了文件，但漏掉消费者或测试 |

评分规则：

- **每个概念只有一个等级。** 一个概念在 spine 上评到 L3、重试时是 L1，那就是今天的 L1，并把第一次的分数留作证据。
- **顺序胜过词汇。** 乱序复述各跳是 L1，不是 L2。
- **锚点胜过正文。** 正确但没有可定位锚点的解释，最高只到 L2。
- **预测必须先于揭示。** 看过代码之后做出的预测不是 L3 的证据。
- **应用必须包含影响范围。** 说出改了哪些文件属于 L3 级回忆；L4 要求说出后果。

## 证据记录

存观察，不存标签。没有证据的等级之后无法重新评分或审计，下一个 agent 继承的是一个它无法信任的论断。

好：

```yaml
- id: request-entry
  canonical: HTTP request entrypoint
  anchor: cmd/server/main.go:42
  level: L2
  confidence: 0.8
  accuracy: 0.6
  evidence:
    - "Prediction: said handlers/ layer receives the request first; actual first hop is cmd/server/main.go:42 router setup."
    - "On teach-back listed router -> handler -> service correctly but placed the middleware after the handler."
  misconceptions:
    - "Middleware runs after handlers."
  next_review: 2026-11-01
```

坏：

```yaml
- id: request-entry
  level: L2
  notes: "User understands the request flow."
```

坏记录没有锚点、没有引用预测、没有具体错误、没有日期。它驱动不了练习，也无法被纠正。

更多坏模式：

| 模式 | 为什么失败 |
| --- | --- |
| `level: L3`，证据是 "answered well" | 没有预测内容；不可验证 |
| 证据是 agent 的解释 | 那衡量的是 agent，不是用户 |
| "Mastered" | 是判决，不是观察 |
| 一条记录里塞五个概念 | 无法分别评分或安排复习 |

## 自信度与准确度

两者都是 `[0, 1]` 区间的数字。

- `confidence` — 直接问："你有几成把握，0 到 1？"记录他们说的数字。
- `accuracy` — 给答案打分：正确且有序 = 1.0；正确但有一步缺失 = 0.5；错误 = 0.0。对该概念的所有观察取平均。

校准：

```
calibration_error = confidence - accuracy
```

| 取值 | 解读 | 动作 |
| --- | --- | --- |
| `> 0.3` | 过度自信 | 先练。不要在这个概念上教新材料。 |
| `0.1 .. 0.3` | 轻微过度自信 | 下次会话提一个预测问题。 |
| `-0.1 .. 0.1` | 校准良好 | 正常间隔。 |
| `< -0.1` | 自信不足 | 说出来；用户懂的比他以为的多。 |

过度自信是优先项。自信不足的用户会求助；过度自信的用户会去重构 spine。

按概念报告校准，绝不报告单次会话的平均值。一个坏概念会藏在好看的平均值里。

## 复习安排

评分后按等级设置 `next_review`：

| 等级 | 间隔 | 理由 |
| --- | --- | --- |
| L0 | 1 天 | 还没有可间隔的东西；先重建锚点 |
| L1 | 1 天 | 定位能力不用就衰减得快 |
| L2 | 3 天 | 解释需要一次巩固 |
| L3 | 7 天 | 预测更稳定，但仍然脆弱 |
| L4 | 21 天 | 应用能力可迁移；偶尔检查 |

规则：

- 一次失败的复习把等级降低一级，并把间隔重置为新等级对应的值。
- L3 或 L4 的复习通过后，可有一次延展到表格之外一步（L3 到 14 天，L4 到 30 天）；不要无限链式延展。
- `drill` 选择 `next_review <= today` 的概念，按 `calibration_error` 降序，再按最久未复习排序。
- 一次练习会话最多 12 个概念。疲劳会产生假阴性，而假阴性会污染 profile。

## 会话级评分

会话结束时记录：

- 触及的概念及其等级变化。
- 发现的最强误解，逐字记录。
- 用户是否达成该阶段的完成测试（`references/curriculum.md`）。
- 一句话说明下次会话从什么开始。

一次既没有等级变化也没有记录误解的会话，通常说明 agent 只是在讲授。在笔记里写明这一点。
