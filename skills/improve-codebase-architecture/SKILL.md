# Improve Codebase Architecture（路径占位）

> 轻量精简版，裁剪自 [mattpocock/skills](https://github.com/mattpocock/skills) 的 improve-codebase-architecture（MIT License, Copyright (c) 2026 Matt Pocock）。若环境已安装同名完整 skill，请优先使用完整版。

本 skill 只标出代码库架构改进的路线，不含完整流程。

- **目标**：找出「深化模块」的机会（把浅模块变深），提升可测试性与 AI 可导航性。
- **基础**：建立在领域模型与共享架构词汇（module / interface / depth / seam / adapter / leverage / locality）之上；领域术语来自 `CONTEXT.md`，决策记录在 `docs/adr/`。
- **无完整流程时**：本技能包不提供扫描与 HTML 报告流程。若环境未安装完整 skill，而你需要术语或 ADR 支持，转 `domain-modeling`（未安装则见 `project-docs-workflow/references/deps/domain-modeling.md`）。
